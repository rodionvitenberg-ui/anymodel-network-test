# Anygateway (антицензурный шлюз)

Контекст проекта: восстановление доступа к AI-сервисам из сетей РФ, где трафик инспектирует ТСПУ. Глоссарий — канонический язык для документации, отчётов и эксплуатации; детали реализации здесь не описываются (см. `research/`, `report/`).

## Language

### Противник и среда

**ТСПУ**:
Комплекс DPI-оборудования на сетях всех операторов РФ под централизованным управлением; единственный противник в этом контексте.
_Avoid_: «РКН-блокировки», «замедление» (ТСПУ не только замедляет)

**Freeze (TCP 16-20)**:
Приём ТСПУ на мобильных сетях: соединение не рвётся, а «замерзает» после ~15–20 КБ сервер→клиент — поток LLM-ответа останавливается без ошибки.
_Avoid_: «обрыв», «бан» (соединение живо)

**Активная проба**:
Попытка фильтра притвориться клиентом, чтобы отличить маскированный туннель от настоящего TLS-трафика к легитимному сайту.

### Транспорт

**Туннель**:
Путь пользователь → клиент → шлюз → интернет, снаружи неотличимый от HTTPS-сессии с легитимным сайтом.
_Avoid_: «VPN» (пользователь читает это как TUN-режим с системным интерфейсом — здесь их нет)

**Шлюз**:
Сервер вне РФ, где туннель терминирует и трафик выпускается в интернет.
_Avoid_: «VPN-сервер», «VPS» (VPS — лишь хостинг шлюза)

**REALITY**:
Режим TLS-маскировки Xray: аутентификация клиента спрятана в обычное TLS-рукопожатие; всё, что не прошло аутентификацию, прозрачно уходит на сайт-одолжитель.

**Сайт-одолжитель**:
Крупный легитимный сайт (dest/SNI), чьё имя и настоящий сертификат одалживаются для маскировки туннеля; выбор ограничен списком «перегретых» доменов из исходников Xray.
_Avoid_: «маска», «прокладка»

**Анти-проба**:
Поведение шлюза при неавторизованном соединении: пробующий видит настоящий сертификат и контент сайта-одолжителя, как будто зашёл на этот сайт.

**Vision (xtls-rprx-vision)**:
Потоковый режим VLESS, не образующий детектируемый паттерн «TLS внутри TLS».
_Avoid_: «xtls» без уточнения

**Fingerprint**:
Отпечаток TLS-рукопожатия клиента (uTLS); каноничное значение — «chrome».

**Короткий ID (shortId)**:
Публичный идентификатор REALITY-аутентификации; секретом не является.

### Клиентская сторона

**Клиент**:
Локальный Xray-процесс на устройстве пользователя с локальными прокси-портами; часть этого проекта, а не стороннее приложение.
_Avoid_: «VPN-приложение», «Hiddify» (сторонние приложения — лишь одна форма клиента)

**Пользователь**:
Человек, для которого открывается доступ. Не путать с клиентом.

**VLESS-строка**:
Самодостаточное текстовое описание всех параметров подключения, включая секреты; единственный носитель, передаваемый пользователю вне репозитория.

**Системный прокси**:
Настройки ОС, направляющие браузер в локальный клиент; включается при старте туннеля и обязательно снимается при его остановке.
_Avoid_: TUN/VPN-режим (не реализован и для браузера не нужен)

**Клиент-сервис**:
Постоянный фоновый сервис, удерживающий клиент запущенным между входами в систему и перезапускающий его при падении.
